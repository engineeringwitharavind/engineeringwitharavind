I'm Aravind, from Chennai, India. I build interfaces.

Mostly React and Next.js. Sometimes the work is making a complex state predictable. Sometimes it's getting animations to feel right. Often it's the parts nobody sees, accessible defaults, error boundaries, the states between states.

I care about:
- Components that compose without leaking assumptions
- Motion that respects physics (people notice when it doesn't)
- Interfaces that work for everyone, not just the happy path

Lately, I’ve been thinking a lot about motion. Not trendy spring physics for the sake of it, but motion that actually helps: guiding attention, providing feedback, making the interface feel like it inhabits the same physics as the rest of the world. When done right, it disappears into intuition.

Currently exploring how animation can clarify rather than decorate, and where AI actually reduces friction vs. where it just adds noise.
